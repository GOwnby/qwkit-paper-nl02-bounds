# Inputs from the N1 study

The files in this folder are copied unchanged from the N1 study (archive: https://doi.org/10.5281/zenodo.23444557, folder
`studies/n1_paper/`), so that the NL-02 scripts in this archive run from this folder alone. They are inputs here;
to regenerate them, run the listed script in the N1 archive.

| File | Role | Generated in the N1 archive by |
|---|---|---|
| `electrodes.json` | input data | `studies/n1_paper/electrode_study.py` |
| `propagation_study.py` | module imported by the NL-02 scripts | (source) |
| `rates.json` | input data | `studies/n1_paper/rates_study.py` |
| `tables.json` | input data | `studies/n1_paper/tables.py` |
| `tables.py` | module imported by the NL-02 scripts | (source) |
| `waveguide.json` | input data | `studies/n1_paper/waveguide_design.py` |
| `waveguide_design.py` | module imported by the NL-02 scripts | (source) |
